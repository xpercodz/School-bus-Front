Colour preview — cyan-blue accent

School Bus Transit · same markup, two token sets

Decision artifact · 3 September 2025 · director review

A cyan-blue accent, on a cooler paper.

Today the app is a warm grey sheet, near-black ink, and route blue for everything that is data: the ground is #f3f4f1, the accent #0f5586, and the one committing button is simply ink. This page puts the same screens on a cooler, lighter ground and moves the single accent into cyan-blue, so paper, ink and data read as three tiers instead of two.

Nothing in src/** is touched. The toggle in the bar above swaps the whole page's --color-* values — the same markup, two token sets — so what you compare is exactly what a one-file change would ship.

How to read it. A filled square is the token's own colour; the two lines beside it are the text pairs that token carries, with the measured ratio. 4.5 is the body-text floor, 3.0 the floor for a field edge or a 1px control boundary. The quiet divider (--color-outline-variant) is deliberately below 3:1 in both sets — it separates two surfaces of the same card, it is not a control edge.

One mapping note, outside the token block. The Arc primary button fills from --foreground (which maps to --color-on-surface), not from --color-primary — that is why today's "Add student" is ink. Making the committing button cyan is one line in src/components/arc/arc-tokens.css (point the Button's primary fill at the accent); without it the accent still lands on every data hue, chip, route line and focus ring, and the button stays ink.

What this does not change: no layout, type size, radius, spacing, motion, component API or status meaning — only the values of the tokens above, plus the optional button mapping. Green, amber and red stay reserved for attendance state.

Remaining verification: the screenshots for this artifact were taken in headless Chrome at 1440 and 390 CSS px; the Arabic (RTL) reading, the real Material Symbols subset, and a device with the actual Android/iOS font rasterisation were not part of this pass.
